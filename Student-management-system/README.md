Student Management System (Tkinter + Pandas)

A simple Python GUI project that manages student records using Tkinter for the interface and Pandas for data storage and analysis.

**#Features**

Add new students with name, roll number, and marks

Automatically assign grades (A+, A, B, C, D)

View and update student data

Store information in a CSV file

Analyze data (average, topper, etc.)

**#Tech Stack**

Python 3

Tkinter — for GUI

Pandas — for data handling

**#How to Run**
git clone https://github.com/exist16vishal/Student-Management-System.git
cd Student-Management-System
pip install -r requirements.txt
python student_gui.py

**#Output**

*GUI interface to manage student records dynamically
*Grades are computed based on marks entered
